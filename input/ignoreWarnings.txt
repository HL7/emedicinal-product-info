# Core textLink cardinality: the Type 4 example links several resources from one section narrative (4.2 Posology: 2 targets; 6.1 List of excipients: 3 targets). The core textLink extension (http://hl7.org/fhir/StructureDefinition/textLink) allows only one occurrence per Narrative, and each textLink has exactly one data target, so a narrative that refers to several resources cannot link all of them, and the validator reports "max allowed = 1". A change request to allow textLink to repeat has been submitted: FHIR-59812 (https://jira.hl7.org/browse/FHIR-59812); discussion on chat.fhir.org: https://chat.fhir.org/#narrow/channel/179252-IG-creation/topic/multiple.20textLink.20extension.20for.20EPI.20-.20validator.20not.20checking/with/639260426.
